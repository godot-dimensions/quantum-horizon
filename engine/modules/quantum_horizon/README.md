# Quantum Horizon Godot C++ Module

This is a Godot module with custom C++ code for Quantum Horizon.

Code should be placed in this module when both of these are true:

- The code needs to be high performance or low level.
  - If performance is not important, prefer using GDScript instead.

- The code is not general-purpose 4D code intended to be shared as open source.
  - If the code is, consider adding it to Godot 4D.
  - If you are not sure, you can always add it here first, and move it to Godot 4D later.

To compile this module, run one of the `build` scripts, or run the `run` script to build and run the Godot editor with this module loaded.
